# Imagens

As fotos do Figma não são redistribuídas neste repositório. Exporte-as do
arquivo **Coffee Shop Mobile App Design (Community)** com estes nomes:

| Arquivo | Origem no Figma (página 🎨 Visual) | Onde aparece |
|---|---|---|
| `onboarding.png` | High-Fidelity (Onboarding) → Image Onboarding | Onboarding |
| `banner.png` | High-Fidelity (Home) → Top → Banner → Banner 1 | Banner da Home |
| `coffee_1.png` | Componente Image/Coffee/2 (Caffe Mocha) | Card, Detail, Pedido |
| `coffee_2.png` | Componente Image/Coffee/3 (Flat White) | Card |
| `coffee_3.png` | Componente Image/Coffee/5 (Mocha Fusi) | Card |
| `coffee_4.png` | Componente Image/Coffee/4 (Caffe Panna) | Card |

Como exportar: selecione o nó no Figma → painel **Export** → PNG 2x → salve aqui.

Enquanto os arquivos não existirem, o componente `ProductImage` desenha um
placeholder com as cores da marca — o app funciona normalmente.
